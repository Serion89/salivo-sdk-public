Salivo Programming Language Guide

A comprehensive reference manual, tutorial, and cheat sheet for building high-performance applications with Salivo.

Key Architectural Highlights: Stream Header Imports (><), Zero-Underscore Data Types, Deterministic RAII Memory (Drop trait), and Postfix ? Error Propagation.

1. Stream Header Imports (><)

Salivo uses >< as the sole import operator in the language. It represents input streams flowing into the application module.

module myapp.main;

><salivo.std.core::{out, outln, assertEq, Result, ok, err};
><salivo.std.fs::{open, close, pathJoin};
><salivo.std.collections::{Vec, vecNew, push, get, veclen};

4. Input, Output & String Interpolation

><salivo.std.core::{out, outln};

pub func main() -> int {
    out("Enter your name: ");
    let name = input();
    
    // Formatting with postfix modifiers (:trim and :upper)
    outln($"Hello, {name:trim:upper}!");
    return 0;
}

6. Functions & Postfix ? Operator

pub func safeDivide(int a, int b) -> Result<int, string> {
    if (b == 0) { return err<int, string>("Division by zero"); }
    return ok<int, string>(a / b);
}

pub func readConfig(string path) -> Result<string, IoError> {
    let handle = open(path, "r")?; // Auto-unwraps or returns Err
    return ok<string, IoError>(readStr(path)?);
}

7. Structs, Enums & RAII Drop

pub struct UserProfile {
    int id;
    string username;
}

pub trait Drop {
    func drop(self);
}

impl Drop for UserProfile {
    pub func drop(self) {
        outln($"Cleaning up user session {self.id:str}");
    }
}
